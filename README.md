# ملاحظات هامة — Important Notes

تطبيق ملاحظات عربي أنيق بواجهة RTL كاملة، يعمل بالكامل داخل المتصفح ويحفظ البيانات في `localStorage`.
يتيح إنشاء حسابات خاصة لكل مستخدم (بريد إلكتروني + كلمة مرور)، مع عزل تام للملاحظات بين الحسابات على الجهاز نفسه، دون أي خادم أو قاعدة بيانات خارجية.

## المزايا

### الحسابات والخصوصية
- تسجيل حساب جديد بالاسم والبريد الإلكتروني وكلمة المرور.
- تسجيل دخول آمن مع التحقق من كلمة المرور المخزّنة كبصمة PBKDF2 وليس كنص صريح.
- عزل كامل للملاحظات: كل مستخدم يرى ملاحظاته فقط، ومفاتيح التخزين منفصلة لكل حساب.
- جلسات دائمة عند تفعيل «تذكرني» (30 يوماً)، وجلسات مؤقتة تُغلق مع التبويب (12 ساعة) عند تعطيله.
- إدارة الملف الشخصي: تعديل الاسم ولون الصورة الرمزية.
- تغيير كلمة المرور مع التحقق من الكلمة الحالية.
- حذف الحساب وكل بياناته نهائياً، مع تأكيد كتابي لحماية إضافية.
- حساب تجريبي جاهز لاستكشاف التطبيق فوراً دون إنشاء حساب.

### الملاحظات والتنظيم
- إنشاء وتعديل وحذف الملاحظات.
- تصنيفات جاهزة: عمل، شخصي، دراسة، أفكار، مهام، عام.
- تثبيت الملاحظات المهمة في الأعلى، وإضافة أي ملاحظة إلى المفضلة.
- ستة ألوان لبطاقات الملاحظات.
- بحث فوري في العناوين والمحتوى.
- فرز حسب آخر تعديل، تاريخ الإنشاء، أو العنوان أبجدياً.
- عرض شبكي أو قائمة، مع تذكّر اختيارك.
- عدّاد كلمات لكل ملاحظة، وإحصائيات عامة (العدد، المثبتة، المفضلة، الكلمات).
- شريط جانبي يعرض التصنيفات وأعدادها، مع نسخة منسدلة على الهاتف.
- حالات فارغة واضحة ورسوم متحركة خفيفة تحترم إعداد تقليل الحركة.

### المظهر وتجربة الاستخدام
- تصميم مؤسسي عربي كامل RTL مبني على متغيرات CSS.
- ثلاثة أنماط: فاتح، داكن، ومتابعة نظام التشغيل.
- استجابة كاملة من الهاتف إلى الشاشات العريضة.
- نافذة محرر ملاحظات متكاملة مع اختيار التصنيف واللون.
- إشعارات Toast، ونوافذ تأكيد، ونوافذ حوارية قابلة للوصول بلوحة المفاتيح.
- دعم قارئات الشاشة وتسميات ARIA، وتنقل كامل بلوحة المفاتيح.
- حماية من الأخطاء: تحقق من الحقول، رسائل خطأ عربية واضحة، ومعالجة امتلاء التخزين.

### البيانات
- تصدير كل الملاحظات إلى ملف JSON.
- استيراد ملاحظات من نسخة احتياطية مع تنظيف وتحقّق كامل.
- مؤشر لاستهلاك التخزين التقريبي من أصل 5 م.ب.
- حذف جميع الملاحظات مع إمكانية التراجع الفوري.

## بيانات الدخول التجريبية

يمكن فتح التطبيق والضغط على زر **«استكشف المنصة بحساب تجريبي»**، أو تسجيل الدخول يدوياً بـ:

| الحقل | القيمة |
| --- | --- |
| البريد الإلكتروني | `demo@notes.app` |
| كلمة المرور | `Demo@1234` |

الحساب التجريبي:
- يُنشأ تلقائياً عند أول استخدام.
- يحتوي على 7 ملاحظات جاهزة تغطي التصنيفات والألوان والمفضلة والتثبيت.
- بريده محجوز ولا يمكن استخدامه في التسجيل العادي.
- يمكن تعديل ملاحظاته مثل أي حساب آخر، وتبقى التغييرات محفوظة على الجهاز.

> إن وُجد حساب عادي سابق بالبريد نفسه على الجهاز، فسيعرض التطبيق رسالة تعارض واضحة بدلاً من فتح الحساب التجريبي.

## التشغيل محلياً

المشروع ثابت بالكامل (HTML/CSS/JS) ولا يحتاج إلى بناء أو تثبيت حزم. يكفي تقديمه عبر خادم HTTP محلي لأن متصفحات حديثة تقيّد بعض واجهات Web Crypto و`localStorage` عند الفتح المباشر عبر `file://`.

### الطريقة 1: Python

```powershell
cd important-notes
python -m http.server 8000
```

ثم افتح: <http://localhost:8000/>

### الطريقة 2: Node.js

```powershell
cd important-notes
npx serve .
```

أو باستخدام `http-server`:

```powershell
npx http-server . -p 8000
```

### الطريقة 3: خادم PowerShell مدمج

إذا لم يتوفر Python أو Node، يمكن استخدام خادم صغير يعتمد على `System.Net.HttpListener`. مثال مبسّط:

```powershell
$root = (Resolve-Path .).Path
$listener = [System.Net.HttpListener]::new()
$listener.Prefixes.Add('http://localhost:8000/')
$listener.Start()
Write-Host 'Serving on http://localhost:8000/'
while ($listener.IsListening) {
  try {
    $context = $listener.GetContext()
    $path = [Uri]::UnescapeDataString($context.Request.Url.AbsolutePath).TrimStart('/')
    if (-not $path) { $path = 'index.html' }
    $file = [System.IO.Path]::GetFullPath((Join-Path $root $path))

    if ($file.StartsWith($root, [StringComparison]::OrdinalIgnoreCase) -and
        (Test-Path -LiteralPath $file -PathType Leaf)) {
      $bytes = [System.IO.File]::ReadAllBytes($file)
      $context.Response.ContentType = switch ([System.IO.Path]::GetExtension($file)) {
        '.html' { 'text/html; charset=utf-8' }
        '.css'  { 'text/css; charset=utf-8' }
        '.js'   { 'application/javascript; charset=utf-8' }
        '.png'  { 'image/png' }
        '.svg'  { 'image/svg+xml' }
        default { 'application/octet-stream' }
      }
      $context.Response.ContentLength64 = $bytes.Length
      $context.Response.OutputStream.Write($bytes, 0, $bytes.Length)
    } else {
      $context.Response.StatusCode = 404
    }
    $context.Response.Close()
  } catch {
    # تجاهل انقطاع الاتصال وأكمل الاستماع
  }
}
```

### ملاحظات التشغيل
- لا توجد متغيرات بيئة ولا خدمات خارجية مطلوبة.
- الخطوط تُحمّل من Google Fonts عند توفر الإنترنت، ومع تعذّره يستخدم المتصفح خطوطاً بديلة محلية.
- التطبيق يعمل دون أي طلبات شبكة بعد تحميل الصفحة الأولى.

## طريقة الاستخدام

1. **ابدأ بحساب:** سجّل حساباً جديداً، أو جرّب الحساب التجريبي.
2. **أنشئ ملاحظة:** اضغط «ملاحظة جديدة» في الشريط العلوي (أو زر الصفحة على الشاشات الكبيرة).
3. **نظّم:** اختر تصنيفاً ولوناً، ثم احفظ.
4. **ثبّت وأضف للمفضلة:** من قائمة النقاط الثلاث على البطاقة، أو من داخل المحرر.
5. **ابحث:** اكتب في شريط البحث، واستخدم التصنيفات من الشريط الجانبي لتضييق النتائج.
6. **رتّب العرض:** بدّل بين الشبكة والقائمة، وغيّر ترتيب الفرز من قائمة الترتيب.
7. **خصّص المظهر:** من الإعدادات ← المظهر، أو من زر المظهر في الشريط العلوي.
8. **أدر حسابك:** من الإعدادات ← الحساب (الاسم واللون)، والأمان (كلمة المرور)، والبيانات (التصدير والاستيراد والحذف).

### ترتيب التحميل

تُحمّل الملفات كسكربتات تقليدية عبر `defer` بالترتيب التالي:

```html
<script src="js/crypto.js" defer></script>
<script src="js/store.js" defer></script>
<script src="js/app.js" defer></script>
```

- `crypto.js` يوفّر `window.HNHash`.
- `store.js` يوفّر `window.HNStore`.
- `app.js` يستهلك الواجهتين ويدير الحالة والواجهة.

> لا توجد وحدات ES ولا حزم npm، لذلك يعمل المشروع مباشرة من أي خادم ثابت.

### مسؤوليات الطبقات

| الطبقة | المسؤولية |
| --- | --- |
| `crypto.js` | توليد الملح، اشتقاق المفتاح بـ PBKDF2-SHA256، التحقق الثابت الزمن تقريباً من البصمة |
| `store.js` | قراءة/كتابة `localStorage`، إنشاء المستخدمين، الجلسات، الملاحظات، التفضيلات، الاستيراد والتصدير |
| `app.js` | ربط العناصر، التحقق من النماذج، العرض والإحصاءات، البحث والفرز، النوافذ والإشعارات، المظهر |

## التخزين ونموذج البيانات

### مفاتيح `localStorage`

| المفتاح | المحتوى |
| --- | --- |
| `hn.users.v1` | مصفوفة المستخدمين: المعرف، الاسم، البريد، بصمة كلمة المرور، لون الصورة، حالة الحساب التجريبي، التواريخ |
| `hn.session.v1` | الجلسة الحالية: `userId`، `createdAt`، `expiresAt` |
| `hn.notes.v1.<userId>` | مصفوفة ملاحظات المستخدم، معزولة بالكامل لكل حساب |
| `hn.prefs.v1.<userId>` | تفضيلات المستخدم: المظهر، طريقة العرض، الترتيب |
| `hn.theme.v1` | المظهر العام المختار قبل تسجيل الدخول: `light` أو `dark` أو `system` |

### الجلسات

- **مع «تذكرني»:** تُحفظ في `localStorage` لمدة 30 يوماً.
- **بدونه:** تُحفظ في `sessionStorage` لمدة 12 ساعة، وتنتهي بإغلاق التبويب.
- تُتحقق صلاحية الجلسة عند كل تحميل، وتُحذف تلقائياً عند انتهائها أو حذف الحساب.

## الأمان وحدوده

### ما يطبّقه التطبيق

- **لا تُخزَّن كلمات المرور كنص صريح.** تُشتق البصمة باستخدام `PBKDF2-SHA256` عبر Web Crypto:
  - 160,000 دورة.
  - ملح عشوائي بطول 16 بايت لكل مستخدم.
  - مفتاح مشتق بطول 256 بت.
- تُخزَّن البصمة والملح وعدد الدورات فقط، ويُجرى التحقق عبر مقارنة ثابتة زمنياً.
- كل حساب يملك مفاتيح ملاحظات وتفضيلات منفصلة، ولا تستطيع واجهة التطبيق عرض بيانات حساب آخر.
- التحقق من المدخلات وتنظيف المحتوى قبل عرضه يقللان من مخاطر الحقن.
- الحساب التجريبي محمي من التعارض مع حساب عادي بالبريد نفسه.

### حدود يجب معرفتها

> **مهم:** هذا تطبيق محلي بالكامل. العزل بين الحسابات عزل على مستوى الواجهة والتخزين المنظم، وليس تشفيراً لبيانات الملاحظات.

- أي شخص لديه وصول إلى المتصفح نفسه يمكنه فتح أدوات المطوّر وقراءة `localStorage` مباشرة، بما في ذلك ملاحظات جميع الحسابات على الجهاز.
- بصمات كلمات المرور تحمي من الاطلاع المباشر على كلمة المرور، لكنها لا تمنع محاولة تخمين كلمة مرور ضعيفة خارج التطبيق.
- لا توجد مزامنة سحابية ولا نسخ احتياطي تلقائي؛ حذف بيانات المتصفح يعني حذف الحسابات والملاحظات.
- لا توجد استعادة كلمة مرور عبر البريد؛ التطبيق يوضّح ذلك صراحة في نافذة «نسيت كلمة المرور».
- لا تستخدم هذا التطبيق لبيانات حساسة على جهاز مشترك، إلا إذا كنت تفهم هذه الحدود.

### توصيات

- استخدم كلمة مرور قوية وفريدة.
- صدّر نسخة احتياطية دورياً من **الإعدادات ← البيانات ← تصدير**.
- لا تحفظ ملفات التصدير في مكان عام؛ فهي تحتوي على ملاحظاتك كنص صريح.
- إذا كنت على جهاز مشترك، استخدم وضع التصفح الخاص وامسح البيانات بعد الاستخدام.

## النسخ الاحتياطي والاستيراد

### التصدير
ينتج ملف JSON بالشكل التالي:

```json
{
  "app": "important-notes",
  "version": 1,
  "exportedAt": "2026-10-29T09:15:00.000Z",
  "user": {
    "name": "سارة العتيبي",
    "email": "demo@notes.app"
  },
  "notes": [
    {
      "id": "note_...",
      "title": "عنوان",
      "content": "نص",
      "category": "work",
      "color": "sky",
      "pinned": false,
      "favorite": true,
      "createdAt": 1793228780909,
      "updatedAt": 1793228780909
    }
  ]
}
```

اسم الملف يتضمن بريد المستخدم والتاريخ لتسهيل التمييز بين النسخ.

### الاستيراد
- يقبل التطبيق:
  - ملفاً مصدّراً من هذا التطبيق.
  - مصفوفة JSON خام من الملاحظات.
  - كائناً يحتوي على `notes` أو `data.notes`.
- يتحقق من كل ملاحظة وينظّف الحقول، ويستبدل المعرّفات بمعرّفات جديدة.
- يتجاهل الملاحظات الفارغة، ويستخدم قيماً افتراضية آمنة للحقول غير الصالحة.
- يفشل بوضوح إذا كان الملف غير صالح أو لا يحتوي على ملاحظات قابلة للاستيراد.

> الاستيراد **يضيف** الملاحظات إلى الحساب الحالي ولا يحذف الملاحظات الموجودة.

## التوافق مع المتصفحات

الإصدارات الحديثة من:

- Chrome / Edge 111+
- Firefox 113+
- Safari 16.4+

يعتمد التطبيق على:
- Web Crypto (`crypto.subtle`) لتجزئة كلمات المرور.
- `localStorage` و`sessionStorage`.
- خصائص CSS حديثة مثل `color-mix()` و`backdrop-filter` و`dvh`.
- `Intl` لتنسيق التواريخ والأرقام.

عند تعذّر Web Crypto (مثلاً في سياق غير آمن)، يعرض التطبيق رسالة توضيحية بدلاً من تعطيل الحسابات بصمت. لذلك يُنصح دائماً بالتشغيل عبر `http://localhost` أو HTTPS.

## التخصيص

### تغيير الهوية اللونية
عدّل المتغيرات في أعلى `css/styles.css`:

```css
:root {
  --brand: #0f9f8f;
  --brand-strong: #0b7c70;
  --accent: #c99a3c;
  --bg: #f3f6f8;
  --surface: #ffffff;
  /* ... */
}
```

وللنمط الداكن، عدّل القيم داخل `[data-theme="dark"]`.

### إضافة تصنيف
أضف عنصراً إلى مصفوفة `CATEGORIES` في `js/store.js`:

```js
{ id: 'health', name: 'صحة', color: '#16a34a' }
```

ثم أضف لوناً افتراضياً مقابلاً في `DEFAULT_NOTE_COLORS` داخل `js/app.js` إن رغبت.

### إضافة لون ملاحظة
أضف المعرّف إلى `NOTE_COLORS` في `js/store.js`، ثم أضف قاعدة CSS في `css/styles.css` بالشكل:

```css
.note[data-color="newcolor"] {
  --note-bg: ...;
  --note-edge: ...;
}
```

### تغيير الحساب التجريبي

## التحقق والاختبار

تم التحقق يدوياً في متصفح حقيقي عبر خادم محلي من:

- الإقلاع، تسجيل الدخول، إنشاء حساب، والحساب التجريبي.
- إنشاء الملاحظات وتعديلها وحذفها، والتثبيت والمفضلة، والبحث والفرز والعرض.
- تغيير المظهر والتفضيلات، واستمرار الجلسة بعد إعادة التحميل.
- تعديل الملف الشخصي وتغيير كلمة المرور، ورفض كلمة المرور الحالية الخاطئة.
- التصدير والاستيراد، وحذف الكل مع التراجع، وحذف الحساب نهائياً.
- النوافذ الحوارية، والإشعارات، والاختصارات، وسلوك الشريط الجانبي على الهاتف.
- عزل الحسابات: حساب جديد لا يرى ملاحظات الحساب التجريبي.
